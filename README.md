ScrimStasis is a desktop native app targeted to amateur and semi-professional League of Legends teams that visualizes, saves and imports game data extracted directly from 
the League of legends client, allowing the possibility to analyze scrims and official matches played in the form of custom lobbies, as well as regular games. The goal of this tool is to ease 
the job for coaches and staff of analyzing and saving the data for scrim games 

The application uses Briar (https://github.com/BlossomiShymae/Briar) as an LCU API wrapper to acces Lol's client's endpoints.

## Features

### Watch recent games 👁️

ScrimStasis shows the list of the 25 most recent games you've played in your current account, which are the same games that will show on your client's history page, including custom games.

### Analyze games 📈

You will be able to click on each game and the application will show a page with basic stats of all of the players, the champion bans of that lobby, and a timeline section where information about
each minute of the game will be shown, like the gold difference over time, the gold difference of each lane matchup and a complete timeline of events in the game (kills, towers destroyed, objectives...)

### Exporting games 💾

Since the games will eventually disappear from your account's history, ScrimStasis allows you to export and save each game in a .json file so that it can be analyzed whenever, even when the game no longer shows in your match history. This .json file is the exact same .json that the API endpoint returns, meaning no information is lost (even the data that is not shown in ScrimStasis) so that if players or the staff wants to analyze it themselves, they can do so. 

This .json files combines both the data returned in the **GET /lol-match-history/v1/games/{gameId}** and **GET /lol-match-history/v1/game-timelines/{gameId}** in a single file, with two fields in the JSON containing the data for each one of the endpoints.

### Importing games 📋

The .json files generated by ScrimStasis can be imported to analyze the games, regardless of the game not being on the client anymore. This allows to preserve the game data indefinitely, and allows players to share this files with the coaching staff so they can use the app to analyze the match.  


## Installation and Usage

ScrimStasis is a self-contained desktop .NET application, so no .NET runtime is needed to be installed. The newest version can be downloaded at [releases](https://github.com/triguii/Scrim-Stasis/releases). To run the app, just open the .exe file contained in the folder. 

ScrimStasis needs to be connected to League's client to display the recent games, but if you just want to open a match from a .json file, it can be done without the need of opening the client.

## Roadmap

Currently, ScrimStasis is in a very early stage and will continued to be updated and supported to add new features and improve the visuals. Some of the major features planned include:

- Analyzing more than one game at a time, so that the combined stats and data for a team can be obtained

- Exporting the game's information in more formats, like .csv, .xlsx... so that they can be more easily visualized without the need for the app or parsing the .json.

- Connecting it to external applications (like Discord) so that the match data can be shared more easily trough common used communication channels in pro teams.

If you have any suggestion for an udpate, or want to contribute to the project, please feel free to do so! As I continue to refine and expand the app's capabilities, your involvement can play a crucial role in shaping its future.
